# OwO Boss Command Generator

Free Windows utility that converts OwO boss information into NeonUtil boss commands.

## Features

- Supports 3 bosses animals
- Automatically calculates QE
- Converts weapons to NeonUtil shortcuts
- Converts passives to NeonUtil shortcuts
- Auto copies generated command
- Dark / Light mode
- Mapping warnings

## How To Use

1. Run `wboss i`
2. Copy boss 1 info and paste into Boss 1
3. Copy boss 2 info and paste into Boss 2
4. Copy boss 3 info and paste into Boss 3
5. Enter HP values if desired
6. Click Generate & Copy Command
7. Paste into Discord

## Example Output

```txt
neon b myself vs 54 chipmunk cstaff swarm crit, 37 chicken rune res, 82 dog cstaff pr wgen -hp 90000 90000 100000 -m -qe65
```
